# GitBook pilot

Aletheia's canonical source remains GitHub. GitBook is a possible additional documentation delivery layer, not a replacement for the independent Apps, Knowledge or Swindon sites.

GitBook offers a free plan and an open-source Community/Sponsored plan subject to eligibility and current terms. Sponsored documentation can show a small advertisement. Published docs support Markdown representations, llms.txt, llms-full.txt and a documentation MCP endpoint. Verify the actual plan and public visibility before relying on these features.

1. Sign in at https://app.gitbook.com/ to check for an existing organisation. No account or project has been confirmed.
2. Create a small documentation space if no existing suitable space is found. Choose the public/free option; do not start a paid trial or grant broad access without approval.
3. Import the Markdown pages from this `docs/` directory. The `SUMMARY.md` defines navigation. Initially use manual import or grant Git Sync only to the intended repository and scope after reviewing the requested permissions. Git Sync can write back; retain source ownership and review changes.
4. Publish the space to its actual GitBook URL. Record the URL, test the public Markdown pages, llms.txt, llms-full.txt and its documented MCP endpoint using a compatible client.
5. Compare the same content on GitHub Pages and GitBook. Check canonical links, access, scope, and actual retrieval. Do not call the MCP endpoint installed or active until tested.

References: [GitBook open-source plan](https://www.gitbook.com/solutions/open-source), [pricing](https://www.gitbook.com/pricing), [Git Sync](https://www.gitbook.com/features/git-sync), [documentation](https://gitbook.com/docs/).
