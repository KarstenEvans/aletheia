The Invisible Website

If an AI cannot find your public information, it has little chance of citing it. But invisibility is not a guilty verdict, and being recommended is not a certificate of trust.

Before you optimise for AI, do an Aletheia Trust Check. Verify identity and claims first; then measure whether real crawlers can reach the site. Never confuse an inaccessible website with a dishonest one.

Is your website a gated community?

HTTPS protects communication and ordinarily helps visitors. Problems arise when a firewall, login wall, DNS fault, redirect, bot challenge, robots.txt rule or JavaScript-only page prevents legitimate retrieval. A human browser working does not prove an AI search crawler can read the same content.

The five questions that matter

  1. Who is it? Verify the domain, publisher, important claims and correction contact without making unsupported allegations.
  2. Can a public visitor reach it? Inspect HTTPS, DNS, redirects and the actual HTML response.
  3. Can appropriate crawlers reach it? Inspect robots.txt, index/noindex directives, server logs and security challenges. Search and model training are separate choices.
  4. Can an answer engine understand it? Publish useful, original, dated information, clear headings, source links and stable page addresses.
  5. Does AI cite it accurately? Test multiple prompts and engines, keep a dated record, and distinguish missing references from errors of fact.

Search access is not model training

OpenAI documents OAI-SearchBot for ChatGPT search discovery and GPTBot for possible model-training collection. Their site-owner choices are separate. Google's AI search features rely on ordinary crawlability, indexing and helpful content, but eligibility never guarantees a citation.

What about Swindon.org.uk?

Its public pages were retrievable by one external search tool on 20 October 2026. That is useful evidence against a total public outage, but not a finished audit of robots.txt, particular AI crawlers, Fasthosts configuration or Search Console. Those checks need origin and account evidence, not assumptions.

The Aletheia method

Run Trust Check, then Site Audit. Record OBSERVED, SOURCE, INFERENCE and NOT TESTED separately. Do not disable security to improve a marketing score. Improve the evidence, then improve visibility.
